# ai-product-hack-2026 — AgentGate

Хакатон AI Product Hack 2026, кейс «auto mode для кодинг-агентов». AgentGate — отдельный сервис-гейт между любым кодинг-агентом и операционной системой: перед каждым вызовом инструмента харнесс спрашивает `POST /v1/decide` и получает `allow | deny | ask`.

Зачем это нужно, если Auto Mode уже есть в Claude Code и Codex: [docs/why-agentgate.md](docs/why-agentgate.md).

## Структура репозитория

| Папка | Направление | Что внутри |
|---|---|---|
| `docs/` | все | Спеки, дизайн, обзор рынка, артефакты. Актуальная спека: `docs/superpowers/specs/2026-09-03-agentgate-v1-design.md` |
| `contracts/` | все | OpenAPI и JSON-схемы запроса/ответа `/v1/decide`, шаблон сообщения для агента при `deny`, эталонный клиент `hook_client.py`. Меняется только PR-ом с упоминанием всех трёх направлений |
| `service/` | 2 — сервис | Ядро AgentGate: FastAPI, ступень 1 (детерминированная), ступень 2 (LLM), Postgres, JSONL-лог |
| `adapters/` | 1 — перехват сессий | Плагины и хуки харнессов (OpenCode, Claude Code, Codex, Kilo), по подпапке на харнесс. Отправляют действие и запрос пользователя в сервис |
| `benchmark/` | 3 — бенчмарк | Внутренний (сравнение моделей внутри сервиса) и внешний (сервис против других решений) |

Каждая папка ведёт свой `README.md`, свои зависимости и тесты. Команды пишут только в своих папках.

## Контракт между направлениями

Харнессы о внутренностях сервиса не знают. Адаптер знает URL сервиса, токен и при желании `profile_id`; отправляет действие, `cwd`, последний запрос пользователя и произвольный `metadata`; получает `decision`, `reason`, `suggest`. Схемы — в `contracts/`.
