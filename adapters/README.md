# adapters — перехват сессий и интеграции с харнессами

Направление 1. По подпапке на харнесс: `opencode/`, `claude-code/`, `codex/`, `kilo/`.

Адаптер делает две вещи: перехватывает вызов инструмента до исполнения (PreToolUse, `tool.execute.before` и т. п.), отправляет в сервис действие, `cwd`, последний запрос пользователя и `metadata`, и доводит решение до харнесса: `allow` — пропустить, `deny` — вернуть агенту текст по шаблону `contracts/deny_message_template.md`, `ask` — штатный диалог харнесса с нашим `reason`.

Адаптер знает только `AGENTGATE_URL`, `AGENTGATE_TOKEN` и (опционально) `profile_id`. При недоступности сервиса поведение задаётся настройкой `on_unavailable: ask | deny` (по умолчанию `ask`); `allow` при недоступности запрещён.

Контракт запроса и ответа — `contracts/`. Эталонный клиент — `contracts/hook_client.py`.
