# Задача 17: сайт openmagi.ru пересобран в чистую статику

Дата: 4 сентября 2026. Спека: `frontend/handoff/README.md` (дизайн-хэндофф из Claude Design). Описание структуры — `frontend/README.md`. Предыдущий шаг — `task-16-frontend-deploy.md` (прототип как есть).

## Что построено

`frontend/site/` без сборщика и без Node:

| Файл | Роль |
|---|---|
| `index.html` | Разметка, тексты по умолчанию на русском, `<title>`, `description`, favicon инлайн-SVG |
| `styles.css` | Токены DS v1 и все стили; radius 0, без градиентов и теней; reduced-motion делает терминал статическим блоком |
| `app.js` | ES-модуль: язык с `localStorage['mg-lang']`, появление по скроллу, скролл-терминал, копирование команды с fallback, офлайн-проба |
| `data.js` | Перенесён из `handoff/` без изменений: словари RU/EN, правила с regex, сценарий терминала, харнессы |
| `config.js` | Ссылки, команда установки, пути хуков, цифры бенчмарка, флаг метрик, `<title>` по языкам |

Решение владельца: чистая статика без сборщика, чтобы менять дизайн и артефакты правкой файлов. Тексты берутся по `data-i18n`, ссылки по `data-link`, разметку трогать не нужно. Удалены `support.js` (69 КБ рантайма с React и Babel из unpkg) и прототипный `index.html`; `handoff/tokens.css` влит в `styles.css`.

Что сохранено из прототипа один в один: структура секций, токены, размеры через `clamp`, поведение терминала (порог `th` на строку, прогресс по `-rect.top / (height - innerHeight)`), проба (нормализация `sudo` и `$`, первый regex побеждает, `safe-read` не показывается в списке), состояние «скопировано» на 2 секунды с `aria-live`.

Что не перенесено сознательно: Lenis (плавный скролл был опциональным, нативный допустим по спеке), переключатель темы (в спеке страницы его нет, у прототипа он был скрытым).

## Проверка

Локально (`python3 -m http.server` из `site/`, headless Chromium через Playwright, 1280×900 и 390×844):

- Консоль: только 404 на `favicon.ico`, закрыто инлайн-иконкой.
- После прокрутки: 8 из 8 блоков `[data-appear]` видимы, 10 из 10 строк терминала показаны, заголовок получает состояние `is-scrolled`.
- Проба: `sudo rm -rf ./build` → `deny` с reason/suggest; `foo bar` → состояние «незнакомая команда»; клик по чипу подставляет пример; 24 правила в 4 группах.
- Язык: переключение меняет `<html lang>`, `<title>`, H1, вердикт и подпись пути хука; выбор сохраняется в `localStorage`.
- Ссылки и команда из `config.js` подставлены во все места; метрики показывают `——` при `null`.
- Полностраничные скриншоты десктопа и мобильного совпадают с прототипом по секциям; на мобильном терминал при реальной прокрутке показывает все 10 строк в окне высотой 449 px.

На сервере после `make deploy` (`git_sha` = `fd7d958`): `index.html`, `app.js`, `styles.css`, `data.js`, `config.js` отдаются с правильными типами (`text/javascript` для модулей), `support.js` — 404 (снесён `rsync --delete`), `www` отвечает 200. Headless-прогон живого сайта: 8 блоков, 10 строк, 24 правила, вердикт `DENIED` для `git push --force`, шрифт Big Shoulders загружен.

## Находки

- Панель браузера в приложении не рисует страницу, пока скрыта: скриншоты после программного скролла выходили чёрными. Проверка перенесена в headless Playwright; выводы выше сделаны по нему.
- Полностраничный скриншот мобильной версии показывал пустой терминал: артефакт того, что после прокрутки к началу счётчик показанных строк сбрасывается в 0 (так и в прототипе). При реальной прокрутке всё на месте.
