# Задача 27 — README проекта под именем OPENMAGI

## Что построено

Корневой `README.md` переписан как витрина продукта OPENMAGI: ценность, одна команда установки, каскад PreToolUse и фильтр PostToolUse, демо, таблица шести харнессов с PR в Kilo Code и OpenCode, цифры бенчмарка (собственный, сравнение с Claude Code Auto Mode, ActBench, выбор модели), устройство сервиса по швам, честные ограничения, карта репозитория и команда.

Иллюстрации лежат в `docs/readme/` и сделаны по дизайн-системе «NERV Brutal» из презентации (палитра `#0B0714 / #7B4FD6 / #B6FF2E / #FF2E4A / #FFC93A`, гекс-сетка, судьи MAGI, иероглифы вердиктов):

- `hero.svg` — вордмарк, три вердикта, панель MAGI, бегущая сканлиния и курсор (CSS-анимация внутри SVG, GitHub её проигрывает).
- `pipeline.svg` — каскад `decide`: агент → шов → MELCHIOR·1 → BALTHASAR·2 → строка вердикта; по линии бежит пакет, ступени подсвечиваются по очереди.
- `inspect.svg` — Context Guard: секреты редактируются, инъекция вырезается.
- `terminal.svg` — сплэш установки с построчным появлением, как в CLI из дизайн-системы.
- `actbench.svg` — столбики 30,4 % → 24,3 % с ростом при загрузке.
- `demo-ui.gif`, `demo-install.gif`, `codex-demo.gif` — из видео презентации (`docs/presentation/assets/*.mp4`), 8 fps, ширина 880, 0,6–3,7 МБ.

## Проверки

- Все пять SVG проходят `xmllint`, отрисованы headless Chrome и просмотрены: текст не выходит за блоки, весь контент виден в нулевой момент анимации (кроме `terminal.svg`, где появление строк и есть эффект).
- Все относительные ссылки README указывают на существующие файлы.
- `rule_id` в примере ответа сверен с кодом: `hard-deny.pipe-exec`.

## Решения

- Шрифты в SVG только системные (Impact / monospace): внешние ресурсы в SVG на GitHub не грузятся.
- Арт персонажей из презентации в README не пошёл: дизайн-система допускает только собственный или лицензированный арт.
- Таблица моделей ступени 2 в README содержит только четыре модели, для которых цифры названы в презентации явно; полная таблица по девяти остаётся в `benchmark/`.

## Отложено

- Презентация (`docs/presentation/`) и артефакты в `docs/artifacts/` остаются незакоммиченными — это чужие рабочие файлы.
