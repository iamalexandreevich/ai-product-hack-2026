Статус: спроектировано. Полная спека — `2026-09-05-agentgate-v4-context-guard-design.md`; здесь остаётся только различение, ради которого этот файл заводился.

## Чем это отличается от экранирования на v2

Разделение принципиальное, и путать их нельзя.

| | Экранирование (v2) | Context Guard (v4) |
|---|---|---|
| Защищает | целостность формата | семантику |
| Мешает | подделать секцию промпта переводом строки | сказать модели «игнорируй инструкции» |
| Механика | `json.dumps` каждого значения | распознавание и нейтрализация инструкций |
| Готовность | написана и проверена в Task 7 | спроектирована |

После v2 `tool-result` не может подделать структуру промпта, но может сказать модели что угодно обычным текстом. v4 закрывает именно второе.

Всё остальное — решения, контракт, каскад, промпт, хранение, инварианты, тесты, критерий готовности и порядок реализации — в датированной спеке `2026-09-05-agentgate-v4-context-guard-design.md`. Список кандидатных направлений, который лежал здесь, ею закрыт: выбраны спаны от модели с детерминированным применением на сервере и детектор секретов на ступени 1.
