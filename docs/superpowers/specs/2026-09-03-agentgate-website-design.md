## 1. Задача

Одностраничный сайт AgentGate. Главная работа страницы — **человек копирует одну команду установки и вставляет её в терминал**. Всё остальное на странице существует для того, чтобы он это сделал.

Вторичная задача — снять два страха, которые мешают поставить гейт:
- «он пропустит опасное» → секция терминала и метрика ASR;
- «он задолбает вопросами и замедлит агента» → метрики FP, Friction, p95 и финал сценария в терминале.

Аудитория: разработчики, использующие CLI-харнессы кодинг-агентов. Технически грамотные, скептичные к маркетинговым обещаниям, читают цифры вместе с методикой.

**Не задача сайта:** документация, каталог скиллов, витрина хакатон-проекта, форма лидогенерации.

### 1.1 Референсы

| Что берём | Откуда |
|---|---|
| Композиция, воздух, крупная тонкая типографика, спокойный ритм секций | apple.com |
| Приоритет одной install-команды в герое | skill.fish |
| Motion-язык: тёмная база, canvas-фон, glow-градиенты, инерционный скролл, appear-on-scroll | mostik.ai |

Референсы служат языком, а не образцом для копирования: у mostik.ai градиенты декоративны, у нас цвет несёт смысл вердикта (см. §2.2).

## 2. Визуальная система

### 2.1 Поверхности и текст

| Токен | Dark (дефолт) | Light |
|---|---|---|
| `--bg` | `#14141A` | `#FBFBFD` |
| `--surface` | `#1F1F27` | `#FFFFFF` |
| `--surface-deep` (терминал) | `#0B0B0F` | `#0B0B0F` — терминал остаётся тёмным в обеих темах |
| `--text` | `#FFFFFF` | `#14141A` |
| `--text-dim` | `#CDCCD9` | `#5A5A6B` |
| `--hairline` | `rgba(255,255,255,.10)` | `rgba(0,0,0,.10)` |

Dark — основная тема, в ней сайт проектируется. Light — корректная, но более спокойная версия: canvas-поле гасится до едва заметного, glow-облака заменяются мягкими тенями. Обе темы обязаны проходить контраст (§11).

### 2.2 Семантические акценты

Цвет на этом сайте означает вердикт. Использовать эти четыре цвета для декора, не связанного с вердиктом, запрещено.

| Токен | Значение | Цвет |
|---|---|---|
| `--allow` | разрешено | `#3ECF8E` |
| `--ask` | спросить пользователя | `#FFBE46`, светлый край `#FFDE9B` |
| `--deny` | запрещено | `#FF5631` |
| `--brand` | нейтральный бренд-акцент | `#956EEE`, светлый край `#AE8EF9` |

Glow-облако за секцией красится в цвет смысла этой секции: за терминалом с `rm -rf` — коралловое, за метриками — фиолетовое, за пробником — нейтральное фиолетовое.

### 2.3 Типографика

- Основной стек: `-apple-system, BlinkMacSystemFont, "SF Pro Text", Inter, system-ui, sans-serif`
- Моноширинный: `"SF Mono", "JetBrains Mono", ui-monospace, monospace`
- Hero H1: `clamp(48px, 7vw, 104px)`, вес 500, `letter-spacing: -0.03em`, `line-height: 1.05`
- Заголовки секций: `clamp(32px, 4vw, 56px)`, вес 500, `letter-spacing: -0.02em`
- Body: `17px / 1.6`, `--text-dim`
- Подписи и методика: `13px / 1.5`, `--text-dim`

Моноширинный шрифт должен быть подобран по **оптическому** размеру к окружающему тексту (обычно на 1px меньше кегля body), иначе кодовые блоки выглядят налепленными.

### 2.4 Сетка и ритм

- Контейнер `max-width: 1120px`, боковые поля `24px` (мобильный) / `48px` (десктоп)
- Вертикальный ритм между секциями: `clamp(96px, 12vh, 160px)`
- Радиусы: `12px` мелкие элементы, `20px` карточки, `28px` крупные блоки
- Тени в dark не используются — глубина строится разницей поверхностей и hairline-границами

## 3. Motion

Ровно пять приёмов. Добавлять шестой нельзя без правки этой спеки.

1. **Lenis smooth-scroll** — инерционный скролл всей страницы. Единственная внешняя зависимость проекта (~3KB). Реализуется первым: он даёт больше половины эффекта «дорогой страницы».
2. **Canvas-поле за героем** — full-bleed `<canvas>`, `pointer-events: none`, за текстом. Сетка узлов, по рёбрам бегут импульсы. Раз в несколько секунд импульс упирается в узел и гаснет коралловым — визуальная метафора гейта, без подписей и объяснений. Частота кадров ограничена, при уходе вкладки в фон анимация останавливается (`visibilitychange`).
3. **Glow-облака** — размытые радиальные градиенты, крупный `scale`, медленный дрейф. Чистый CSS (`filter: blur()` + `@keyframes`), без JS.
4. **Appear-on-scroll** — `opacity 0→1` + `translateY 24px→0`, `cubic-bezier(0.16, 1, 0.3, 1)`, 600ms, срабатывает **один раз**. Только через `IntersectionObserver`; scroll-listener запрещён.
5. **Scroll-driven терминал** — единственная анимация, привязанная к позиции скролла (§5).

### 3.1 prefers-reduced-motion

При `prefers-reduced-motion: reduce` обязательно:
- Lenis не инициализируется, скролл нативный;
- canvas рисует один статичный кадр и останавливается;
- glow-облака статичны;
- appear-on-scroll — мгновенное появление без сдвига;
- терминал показан целиком в финальном состоянии, sticky снят.

Это требование приёмки, а не улучшение. Скролл-джекинг без выхода — основной способ испортить сайт этого типа.

| # | Блок | Задача |
|---|---|---|
| 0 | Sticky-хедер | Лого, GitHub, переключатель темы, переключатель языка |
| 1 | Hero | Заголовок + install-команда + копирование |

| 3 | Метрики | 4 цифры из benchmark/ |
| 4 | Правила + пробник | Паттерны риска слева, ввод и вердикт справа |
| 5 | Харнессы | Kilo Code / OpenCode / Pi + путь к конфигу |
| 6 | Футер | Повтор команды, GitHub, лицензия, команда |

### 4.0 Хедер

Прозрачный над героем, при скролле получает `backdrop-filter: blur(20px)` и hairline снизу. Высота 56px. Слева вордмарк AgentGate, справа: ссылка на GitHub, переключатель темы (иконка), переключатель языка (`EN`/`RU` текстом). Переключатели — не выпадающие меню, а тумблеры в один клик.

### 4.1 Hero

Композиция по центру, высота `min-height: 92vh`, canvas-поле на фоне.

- **H1, две строки:** `Your agent can do anything.` / `Now it has to ask.`
  Вторая строка — цветом `--text-dim`, чтобы контраст читался как смена реплики.
- **Подзаголовок, одна строка:** `A policy gate between any coding agent and your machine. Every tool call is checked before it runs.`
- **Командная капсула** — центральный объект страницы:
  - фон `--surface-deep`, радиус 14px, паддинг `18px 20px`, hairline-граница
  - `$` цветом `--text-dim`, затем команда моноширинным `--text`
  - справа иконка копирования
  - **вся капсула кликабельна**, не только иконка; `cursor: pointer`
  - при клике иконка на 2000ms меняется на галочку цветом `--allow`, `aria-live="polite"` объявляет `Copied`
  - фолбэк: если `navigator.clipboard` недоступен — выделение текста через `Range` + `document.execCommand('copy')`; если и это не сработало, команда выделяется целиком, чтобы человек скопировал вручную. Молча падать нельзя.
- **Строка под капсулой**, мелким `--text-dim`: `Detects Kilo Code, OpenCode and Pi automatically.` — этим закрывается автодетект, отдельный блок про него не нужен.

**Команда (placeholder, подставить финальную перед запуском):**

    curl -fsSL https://agentgate.dev/install.sh | sh

Команда одна и та же для всех харнессов; выбор харнесса на сайте отсутствует — скрипт определяет установленные харнессы сам.

## 5. Секция «Терминал»

Полноширинный блок `--surface-deep`, внутри окно сессии с тремя точками в заголовке и подписью пути проекта.

### 5.1 Смысл

Секция доказывает **не то, что мы блокируем**, а то, что **сессия не ломается**. Скептик боится не пропущенного `rm -rf`, а того, что гейт превратит агента в бесполезного паникёра. Поэтому сценарий обязан заканчиваться успешно выполненной работой.

### 5.2 Сценарий (построчно)

    > clean up the old migrations

    ● Reading ./migrations
      ✓ allow                                    12ms
    ● Bash: ls -la ./migrations
      ✓ allow                                     9ms
    ● Bash: rm -rf ./migrations

      ┌ AgentGate ─────────────────────────────┐
      │  DENY                                   │
      │  reason: recursive delete outside the   │
      │          declared work scope            │
      │  suggest: move to .trash/ and let the   │
      │           user confirm                  │
      └─────────────────────────────────────────┘

    ● Bash: mkdir -p .trash && mv ./migrations .trash/
      ✓ allow                                    14ms
    ● Done. Moved 12 files to .trash/ — nothing deleted.

Строки `allow` — с галочкой `--allow` и латентностью справа. Блок гейта — рамка и заголовок цветом `--deny`, glow-облако секции в этот момент коралловое.

### 5.3 Требование к содержимому

Сессия должна быть **снята с реально работающего сервиса** и вставлена в страницу как статические данные. Придумывать `reason` и `suggest` нельзя: формулировки гейта — часть продукта, и расхождение между сайтом и реальным ответом будет замечено первым же человеком, который поставит гейт.

### 5.4 Механика

- Секция `position: sticky`, ход прокрутки ~150vh.
- Прогресс считается из позиции секции во вьюпорте (`IntersectionObserver` + `getBoundingClientRect`), не из глобального scroll-listener.
- Строки появляются **построчно** (`opacity` + `translateY 8px`), шаг 40–120ms. Посимвольная печать не используется: дорого по кадрам и выглядит дёргано.
- Темп неравномерный: `allow`-строки идут быстро, блок `DENY` держится заметно дольше остальных.
- **Скролл не захватывается.** Быстрая прокрутка показывает финальное состояние и пропускает секцию.

## 6. Секция «Метрики»

Четыре цифры в ряд (на мобильном 2×2). Метрики — из методики `benchmark/README.md`.

| Цифра | Подпись |
|---|---|
| ASR | catch rate on dangerous actions |
| FP | false blocks on safe work |
| p95 | decision latency |
| Friction | prompts per session |

Числа анимируются счётчиком при входе во вьюпорт (600ms, easing из §3, п. 4). Под рядом одна строка `13px`, `--text-dim`: методика, размер выборки, дата прогона, ссылка на `benchmark/`.

### 6.1 Запрет на выдуманные числа

На момент написания спеки прогона бенчмарка нет. Дизайнер верстает блок с плейсхолдерами `——` и **не имеет права подставить правдоподобные числа**. Если к моменту запуска цифр нет — блок скрывается целиком через фича-флаг `SHOW_METRICS = false`.

Обоснование: сайт продаёт доверие к системе принятия решений. Выдуманный «99.2% catch rate» разрушает ровно то, что мы продаём, и делает недоверчивыми также и настоящие цифры позже. Отсутствие блока — меньший ущерб, чем красивая ложь.

Строка про выборку и дату обязательна: для этой аудитории цифра без методики хуже, чем её отсутствие.

## 7. Секция «Правила + пробник»

Два столбца в общей рамке `--surface`, на мобильном — вертикальный стек (список сверху, пробник снизу, пробник липнет к низу экрана при прокрутке списка).

### 7.1 Список паттернов риска (слева)

10–14 карточек, четыре группы:

- **Destructive** — `rm -rf <path>`, `git push --force`, `DROP TABLE`
- **Exfiltration** — чтение `.env`, `curl` в незнакомый домен, `git remote add`
- **Scope** — запись вне рабочей директории, правка `~/.ssh`
- **Irreversible** — `git reset --hard`, деплой в prod

Карточка: паттерн моноширинным, справа чип вердикта по умолчанию (`deny` / `ask`) в соответствующем цвете. Карточка кликабельна и является кнопкой (`<button>`), не `<div>`.

### 7.2 Пробник (справа)

- Поле ввода с префиксом `$`, моноширинное, `placeholder: try a command…`
- Под ним карточка вердикта
- **Клик по карточке слева подставляет команду в поле и сразу проигрывает вердикт.** Это связывает столбцы в один объект и снимает проблему пустого поля.

### 7.3 Данные и матчинг

Полностью офлайн, без сети. Зашитый JSON на 20–30 записей:

    {
      "id": "rm-rf",
      "match": { "type": "regex", "value": "^\\s*rm\\s+(-[a-zA-Z]*r[a-zA-Z]*f|-[a-zA-Z]*f[a-zA-Z]*r)\\s" },
      "decision": "deny",
      "reason": "…",
      "suggest": "…"
    }

Перед матчингом ввод нормализуется: схлопывание пробелов, срезание `sudo`, срезание ведущего `$`.

### 7.4 Поведение на нераспознанной команде

Вердикт не выдумывается и ошибка не показывается. Показывается нейтральное сообщение:

    This offline demo knows ~30 commands. The real gate evaluates anything.

и три кликабельных примера рядом.

Обоснование: соврать вердиктом на незнакомой команде наносит доверию больше вреда, чем честное признание границ демо. Аудитория будет намеренно проверять пробник на краевых случаях.

### 7.5 Единая форма вердикта

Карточка вердикта повторяет структуру ответа `/v1/decide`: `decision`, `reason`, `suggest`. Та же вёрстка используется в блоке гейта внутри терминала (§5.2). Это должен быть один переиспользуемый компонент, а не две похожие вёрстки.

## 8. Секция «Харнессы»

Узкая полоса, три логотипа в ряд: **Kilo Code**, **OpenCode**, **Pi**. Под каждым — одна строка с конкретным путём, куда пишется хук (не «поддерживаем», а «пишем сюда»).

Полоса стоит после доказательств намеренно: это последний технический вопрос перед установкой — «а мой ли это инструмент», — а не витрина партнёров.

### 8.1 Логотипы

- Источники: `kilocode.ai`, `opencode.ai`, репозиторий `earendil-works/pi`
- Рендер монохромный через `currentColor`, работает в обеих темах
- При наведении логотип набирает `--brand`, подпись светлеет до `--text`
- **Фолбэк:** если официального SVG нет или лицензия не позволяет использование — ставится набранный вордмарк основным шрифтом сайта. Перерисовывать логотипы «по мотивам» запрещено.

## 10. Техстек

Намеренно минимальный: один статический HTML + CSS + модульный JS. Без сборки, без фреймворка.

Обоснование: страница одна, состояний мало. Любой билд-шаг здесь добавляет обслуживания больше, чем экономит кода, и мешает быстро править тексты перед защитой.

- **Единственная внешняя зависимость — Lenis** (~3KB), для §3, п. 1.
- Всё остальное своими силами: `IntersectionObserver`, CSS-переменные, `<canvas>` вручную.
- **GSAP не подключать.** Нужное от него — примерно 40 строк собственного кода.

### 10.1 Темы и язык

- Тема и язык — `data-theme` и `data-lang` на `<html>`, значения в `localStorage`.
- Дефолт темы: `dark`, но при первом визите уважается `prefers-color-scheme: light`.
- Все тексты обеих локалей — в одном JS-объекте-словаре. Текст не размазывается по разметке.
- `<html lang>` обновляется при переключении языка.

## 11. Чек-лист приёмки

Проверяется до сдачи, каждый пункт — да/нет:

- [ ] Копирование команды работает и имеет фолбэк; молчаливого отказа нет
- [ ] `prefers-reduced-motion: reduce` отключает все пять приёмов движения (§3.1)
- [ ] Скролл нигде не захватывается: быстрая прокрутка проходит терминал насквозь
- [ ] Клавиатурная навигация проходит всю страницу; фокус видим на тёмном фоне
- [ ] Контраст текста ≥ 4.5:1 в **обеих** темах, включая текст поверх glow-градиентов
- [ ] Все интерактивные элементы — настоящие `<button>` / `<a>`, не `<div>` с обработчиком
- [ ] Мобильный: терминал не требует горизонтального скролла; sticky-секция не ломает прокрутку
- [ ] Русские строки не рвут вёрстку (они на 20–30% длиннее английских)
- [ ] Метрики: либо реальные числа с методикой, либо плейсхолдеры/скрытый блок — выдуманных чисел нет
- [ ] Пробник на нераспознанной команде показывает сообщение §7.4, а не вердикт
- [ ] Canvas останавливается при уходе вкладки в фон
- [ ] Логотипы харнессов — официальные SVG либо вордмарк-фолбэк
