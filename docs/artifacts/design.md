### Акценты
| Токен | HEX | Роль |
|---|---|---|
| `brand` | `#7B4FD6` | бренд, заливка судей MAGI, толстые линии 6px, вторая половина логотипа |
| `lime` | `#B6FF2E` | заголовки разделов, статус ONLINE, verdict **allow**, бейдж-плашка «MAGI SYSTEM ONLINE» |

| `deny` | `#FF2E4A` | verdict **deny**, тревога |
| `ask` | `#FFC93A` | verdict **ask**, ожидание |

### Правила
- Фон всегда `bg`. Максимум два фона на экран: `bg` + `panel`.
- `brand` используется заливкой (не текстом на тёмном — контраст низкий). Текст на `brand` — `text` или `on-purple`.
- `lime` — только как сигнал/заголовок. Никогда как фон больших областей.
- Текст на цветных плашках (`lime`, `deny`, `ask`) — `bg` (#0B0714).
- Градиентов нет. Скруглений нет (radius 0). Теней нет.

### Паспорта юнитов (цветовые триады)
Триада = 3 полосы в пропорции 3 : 1 : 1. Использовать как акцентную полосу, разделитель, метку категории.

| Юнит | Цвета | Смысл в продукте |
|---|---|---|
| UNIT-00 | `#E8A020` · `#2A5EA8` · `#F2EEFB` | прототип, dev-окружение |
| UNIT-01 | `#7B4FD6` · `#B6FF2E` · `#FF6A00` | бренд, основной сервис |
| UNIT-02 | `#FF2E4A` · `#FF6A00` · `#F2EEFB` | тревога, deny, инциденты |
| UNIT-03 | `#14101C` · `#2A3A6A` · `#7D7391` | заражённые данные, taint |

## 3. Компоненты

### 3.1 Вердикты (allow / deny / ask)
Плашка без скруглений, padding 10px 16px, текст `bg`. Слева иероглиф (Noto Sans JP 900, 22px), справа две строки: название (Big Shoulders 900, 18px, letter-spacing .04em) и пояснение (mono 10px).

| decision | Иероглиф | RU | Фон | Пояснение |
|---|---|---|---|---|
| allow | 承認 | РАЗРЕШЕНО | `lime` | allow · кэш на сессию |
| deny | 否定 | ЗАПРЕЩЕНО | `deny` | deny · причина агенту |
| ask | 審議中 | НА РАССМОТРЕНИИ | `ask` | ask · спросить пилота |

Компактная форма для строк лога: только иероглиф + слово тем же цветом текста на `panel`.

### 3.2 Панель MAGI (три судьи)
Сетка 3 колонки, gap 4px, без скруглений, min-height 130px, padding 16px.

| Блок | Соответствие | Заливка | Статус |
|---|---|---|---|
| MELCHIOR·1 | Ступень 1 — детерминированная (hard-deny → профиль → provenance → allowlist, ~1 мс) | `brand`, текст `text` | `■ ONLINE` лаймом |
| BALTHASAR·2 | Ступень 2 — локальная модель (Qwen 0.8–4B, первый токен A/D/U, 30–100 мс) | `brand` | `■ ONLINE` лаймом |
| CASPER·3 | Ступень 3 — облако, опция (CoT только на U, выкл. по умолчанию) | `panel` + border 1px `line-strong`, текст `text-2` | `□ STANDBY` серым |

Структура блока: имя (Big Shoulders 900, 26px) → подзаголовок «СТУПЕНЬ N · …» (mono 11px, `on-purple`) → описание (mono 11px) → статус внизу (margin-top:auto).

Под сеткой — **строка вердикта**: фон `panel`, border-left 6px `brand`, padding 12px 16px. Слева контекст «ВЕРДИКТ · shell · rm -rf ./build · profile default-dev» (`text-3`), справа иероглиф + слово в цвете вердикта + «stage 1 · 0.8 мс».

### 3.3 Шапка / hero
Служебная строка лаймом (mono 11px, .2em) → wordmark → лид. Снизу линия **6px `brand`**, padding-bottom 20px. Справа при необходимости — таблица метаданных (mono 11px, `text-3` / `text`).

### 3.4 Плитки харнессов
Квадрат (aspect-ratio 1), фон `panel`, по центру монограмма Big Shoulders 900 24px + подпись mono 9px `text-3`. Монограммы: **CC** claude code · **CX** codex · **KI** kilo · **OC** opencode · **PI** pi. Чужие логотипы не используем.

### 3.5 Палитра-образцы
Квадрат 64px + HEX (mono 11px) + роль (mono 10px `text-3`). Фон-образец получает border 1px `line`.

### 3.6 Слот под арт
Прямоугольник, radius 0, подпись «Ваш арт: Ева / персонаж / кадр». Только для собственных изображений.

## 4. CLI-сплэш (установка)

Окно: фон `bg`, border 1px `line`, заголовок «zsh — openmagi install» (mono 11px `text-3`, три серых кружка `line`). Тело: padding 22px 24px, JetBrains Mono 12.5px, line-height 1.45. Поверх — сканлайны `repeating-linear-gradient(0deg, rgba(0,0,0,.28) 0 1px, transparent 1px 3px)` (отключаемо).

Порядок строк:
1. `$ curl -fsSL https://openmagi.dev/install.sh | sh` — `$` цветом `text-3`
2. Блочный логотип (5 строк, line-height 1): `OPEN` — `brand`, `MAGI` — `lime`
3. `v0.1.0 · гейт для кодинг-агентов · fail-closed · профиль default-dev` — `text-3`
4. Три строки судей: имя на плашке (`brand`, для CASPER — `panel`), описание, статус `■ ONLINE` лаймом / `□ STANDBY` серым
5. `✔` лаймом — установлено, обнаружены харнессы
6. `→` оранжевым — следующие команды (`openmagi install claude-code`, `openmagi serve`)
7. Плашка `lime` « MAGI SYSTEM ONLINE » + `承認 allow · 否定 deny · 審議中 ask` + мигающий курсор `lime`

## 5. Голос и словарь
- Язык интерфейса — русский, служебные метки — латиница в верхнем регистре, вердикты дублируются иероглифом.
- Тон: сухой, командный, без восклицаний. «Вердикт», «ступень», «профиль», «пилот» (= разработчик), «харнесс».
- Кодовые имена: MAGI — сама двухступенчатая система решений; MELCHIOR·1 / BALTHASAR·2 / CASPER·3 — ступени; UNIT-xx — цветовые категории; NERV · TOKYO-3 — декоративные метки штаба.
- Всё остальное из вселенной — атмосфера, не функция. Оригинальный арт (Евы, персонажи, кадры) — только собственный или лицензированный, через слоты.

## 6. Слайды (1920×1080)
- Фон `bg` + гекс-сетка. Один слайд — одна мысль.
- Заголовок: Big Shoulders 900, 72–96px, UPPERCASE, белый; акцентное слово — `brand`.
- Маркер раздела в левом верхнем углу: mono 24px, `lime`, «02 · КАК ЭТО РАБОТАЕТ».
- Нижняя линия 6px `brand` или полоса триады UNIT-01 (3:1:1).
- Данные — mono, вердикты — плашками, архитектура — панель MAGI.
- Секционные слайды: wordmark-размер заголовка на всю ширину, ничего больше.
